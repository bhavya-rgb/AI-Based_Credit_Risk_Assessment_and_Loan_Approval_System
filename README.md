.# AI-Based Credit Risk Assessment and Loan Approval System

## Overview

The AI-Based Credit Risk Assessment and Loan Approval System is a smart financial application designed to assist banks and lending institutions in evaluating loan applications efficiently. The system uses machine learning techniques to analyze applicant financial information, predict credit risk, and provide intelligent loan approval recommendations.

The platform automates risk assessment, reduces manual effort, improves decision consistency, and supports data-driven lending decisions.

---

## Key Features

### Applicant Management
- Register and manage applicant information
- Maintain borrower profiles
- Store financial and employment details

### Loan Application Processing
- Create and manage loan applications
- Capture loan amount, income, debt, and credit information
- Track application status

### AI-Based Credit Risk Assessment
- Predict probability of default
- Generate risk scores
- Categorize applicants into risk bands

### Loan Decision Support
- Auto Approve
- Manual Review
- Reject Recommendation

### Dashboard & Analytics
- Risk assessment statistics
- Application monitoring
- Loan approval tracking
- Model performance overview

### Admin Module
- Dataset management
- Model training
- Model registry
- Risk assessment monitoring

## Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/AI-Based-Credit-Risk-Assessment-and-Loan-Approval-System.git
```

2. Navigate to the project directory

```bash
cd AI-Based-Credit-Risk-Assessment-and-Loan-Approval-System
```

3. Configure MySQL database credentials in `application.properties`

4. Run the Spring Boot application

```bash
mvn spring-boot:run
```

5. Open the application in your browser

```text
http://localhost:8080
```
